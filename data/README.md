# Dataset

Source: [Real / Fake Job Posting Prediction](https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction), a copy of EMSCAD (Employment Scam Aegean Dataset).

Run `python download_data.py`. If the endpoint asks for sign-in, download the ZIP from the source page yourself, extract `fake_job_postings.csv`, and put it in this directory. Never substitute an unlabelled or synthetic file and report it as EMSCAD.

The raw CSV is excluded from Git and the review ZIP. Follow the source's dataset usage terms before redistribution. The generated model is included in the review ZIP for immediate use; retraining needs the CSV.

This is historical English job-posting data, not a direct sample of Indian internship letters or WhatsApp messages. It does not establish real-world fraud detection performance.
