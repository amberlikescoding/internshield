# The single training dataset

`india_jobs.csv` contains **119 synthetic Indian English/Hinglish recruitment messages**. Both training and evaluation use different partitions of this one CSV. There is no separate diagnostic dataset.

## Source and attribution

Ridham115, **Indian Scam SMS (synthetic, audited)**:
https://huggingface.co/datasets/Ridham115/indian-scam-sms-synthetic-audited

Source file: `data/synthetic_audited.csv` in the source repository. The dataset card lists [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and additional generator-provider terms; consult the card. The card requests links to its repository and the originating AI Scam & Phishing Message Detector project. The originating project is referenced from the source dataset page; retain that attribution chain when redistributing.

The supplied CSV is a modified subset: `topic=job_offer`, languages English and Hinglish, seven exclusions, labels mapped safe=0/scam=1, whitespace cleaned, columns reduced. `dataset_info.json` preserves source URL, checksums, language/topic filters, class counts and exact exclusion reasons. `source_id` allows tracing each row to the original. No source labels were changed. Exclusion is not a finding that a source label is incorrect; we excluded ambiguity rather than inventing an outcome.

## Fields

| Column | Use |
|---|---|
| source_id | Source traceability, never used as a text feature |
| text | The only classifier input |
| label | 0 = source safe scenario, 1 = source scam scenario |
| language | Documentation only, never fed to classifier |

## Optional refresh

```bash
python download_data.py
```

This downloads the source into memory and writes only the prepared `india_jobs.csv`, plus provenance JSON. No old job-posting dataset is used. SSL checking stays enabled. The included CSV supports offline training if downloading fails.

The raw source messages were generated by language models, and their audit was largely AI-assisted. Review here is assistant content review, not independent human verification or evidence of real-world outcomes. Small synthetic splits can yield high scores without establishing performance on real users' messages.
